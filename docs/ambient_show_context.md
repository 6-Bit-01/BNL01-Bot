# Ambient show evidence

This continues Stage 4 of the locked September 7 recovery plan and its existing
Ambient-currentness finding (C7). The affected boundary is the context supplied
to `generate_dynamic_ambient`.

The previous prompt called the Friday 18:40–21:40 calendar window `live_now`
and permitted active-broadcast claims. After 21:40 it called the show over.
Neither conclusion was supported by a current operational observation.

Calendar time describes the schedule. Current public website state describes
the production session and queue. A fresh TikTok collector observation describes
the observed livestream connection. These are separate sources: an open queue,
a scheduled window, or an unfinished session does not prove a live broadcast;
missing or stale collector evidence does not prove that the show ended.

The Ambient caller uses the existing website read-model and TikTok snapshot
readers, including their existing availability, freshness and public-visibility
contracts. The global collector is bound to the configured Network guild. Its
public connection observation is independent of website availability and queue
visibility; a private queue never supplies public session details. Context stays
transient. The existing Ambient generation, accounting,
selection and delivery owners remain responsible for the message.

Verification must capture the real Ambient prompt with external transports
replaced: a scheduled Friday with no current evidence, a live observation outside
the old three-hour window, unavailable or stale evidence, and private queue
fields. These checks establish source delivery and source meaning, not a live
provider answer or a production publication.

This change leaves the existing posting cadence, capacity, Occasion scheduling,
queue operations and feature settings in place. It does not add a response
classifier, phrase parser, provider repair pass or durable store. Prior show-quote
acceptance and unaffected memory-lifecycle evidence carry forward. The remaining
solo/group acceptance and natural publication evidence keep their original
eleven-row meanings.
