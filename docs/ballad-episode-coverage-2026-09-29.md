# Broadcast Ballads: episode coverage and independent compositions

The Ballad adapter reused the ordinary chat recap query on every generation.
That query selected ten authored examples and a small operational selection.
It also included BNL's earlier replies. This made a long episode look like
the same few anecdotes and exposed provisional mid-show statistics as source
material for a finished-show song. The catalog supplied only one version per
show, so earlier attempts disappeared from the writer's variety context.

## Change

`broadcast-ballad-6` reads the exact finalized, authorized episode through
the existing show owner. It reopens current public TikTok originals and uses
the existing public Discord interval reader. All eligible human messages are
ordered on the show clock with compact person and track references. The whole
roster and operational chronology accompany them. No old BNL reply, frequency
ranked topic list, or selected-chat recap substitutes for original evidence.
Existing source scan bounds still apply; source unavailability cannot fall
back to stale cached chat. Partial reads are labeled.

Roster submissions, terminal outcomes and temporal track association have
different meanings. The brief labels them and forbids inferring full plays
from a Finish flag or summing repeated playback events. The durable episode
does not contain final room tap telemetry. It explicitly marks that total
unavailable and instructs the writer to omit unsupported numerical claims.
This fixes propagation of an old count; it does not invent or backfill the
missing final measurement. A producer's lyric edit remains creative history,
not a new operational source of truth.

Fresh compositions receive the selected catalog versions plus up to twelve
additional distinct creative approaches from the current episode's latest
64 versions. Restores and edits with unchanged title/style/palette are
deduplicated. Literal line endings are no longer supplied as exemplar text.
The writer is directed to consider different exchanges and human stories,
then make distinct choices in theme, hook, emotional movement, rhythm,
instrumentation, vocal character and structure. A genre label change alone
is insufficient. Producer constraints still win. An explicit Polish retains
its selected draft rather than applying new-song requirements.

There is one provider attempt per command, with unchanged routes, output
allowances and spending controls. Full episode input costs more than ten
excerpts; compact references reduce repeated labels and the existing budget
reservation accounts for it. There is no added model critic, retry loop,
scheduler, source store or memory authority.

After generation the worker reopens the evidence off the Discord event loop.
Changed or unavailable source state fails the pending command without returning
the generated draft or modifying previous versions. Transport replay preserves
that failure receipt and does not make another paid call.

## Verification and acceptance

The real September 25 episode was replayed through the reader without model
generation or production writes: 2,063 eligible TikTok messages and eight public
Discord messages were included, with 47 roster submissions and the full
chronology. The compact evidence occupied 134,777 characters. Final recorded
outcomes were 42 finished, four removed and one active; those labels do not
establish full-listen counts. The former bot reply was absent.

Offline regressions cover thousands of originals across the entire episode,
fresh sources before ledger refresh, source withdrawal, exact guild/show
isolation, private-row exclusion, absent originals, unavailable Discord,
distinct prior attempts, source changes during generation, idempotent receipts
and preservation of existing drafts and selected recordings.

Code tests cannot certify artistic variety. After an owner-authorized deployment
and private audition, compare new drafts from the same episode for different
source-grounded stories and audibly different arrangements, with coherent
personal details and accurate numeric scope. Preserve original drafts. Do not
publish test songs or advance other production gates. No data migration is
needed; rollback is an ordinary code revert and bot restart.
